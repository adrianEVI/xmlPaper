# Reglas del Proyecto xmlPaper

1. **Planes de Implementación:**
   - Cada vez que se cree o actualice un plan de implementación (`implementation_plan.md`), guarda siempre una copia del plan en formato Markdown en la carpeta `PlanesImplementacion/` con un nombre descriptivo del tema abordado (por ejemplo, `PlanesImplementacion/Plan_NombreTema.md`).
